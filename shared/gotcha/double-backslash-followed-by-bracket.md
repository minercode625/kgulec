# `\\` 다음 줄이 `[`로 시작하면 "Illegal unit of measure" 에러

## 증상

tcolorbox/본문에서 줄바꿈 `\\` 직후의 다음 줄이 대괄호 `[`로 시작하면 컴파일이 실패한다:

```
! Illegal unit of measure (pt inserted).
<to be read again>
                   5
l.329 \end{frame}
```

에러 라인이 `\end{frame}`을 가리키지만, 실제 원인은 그 안의 `\\` + `[` 조합이다.

## 원인

LaTeX의 `\\`는 **선택적 인수** `\\[<길이>]`(추가 수직 간격)를 받는다. `\\` 뒤에 (공백·줄바꿈을 건너뛰고) `[`가 나오면, LaTeX은 그 대괄호 안을 길이 값으로 해석하려 한다. 프롬프트 예시처럼 `[역할]`, `[작업]`, `[형식]` 같은 **대괄호 라벨**을 줄 시작에 두면 "역할"·"10장" 등이 길이 단위로 파싱되어 에러가 난다.

```latex
% 에러 발생!
\scriptsize \ttfamily
[역할] 학부 2학년 대상 CS 교수\\
[작업] '경사하강법' 50분 강의 개요\\
[형식] 슬라이드 10장 · 제목+불릿 3개\\
[제약] 수식 전에 직관 설명 먼저
```

## 해결 방법

`\\` 직후에 빈 그룹 `{}`를 붙여 선택적 인수 스캔을 멈춘다.

```latex
% 안전
[역할] 학부 2학년 대상 CS 교수\\{}
[작업] '경사하강법' 50분 강의 개요\\{}
[형식] 슬라이드 10장 · 제목+불릿 3개\\{}
[제약] 수식 전에 직관 설명 먼저
```

## 일반 규칙

- `\\` 다음 줄(또는 같은 줄 이어서)이 `[`로 시작하면 항상 `\\{}`로 끊는다.
- 의도적으로 간격을 줄 때만 `\\[0.3cm]` 형태를 쓴다.
- 같은 함정이 `\item`, `\\`를 받는 다른 환경에서도 대괄호 라벨과 만나면 발생한다.
