# `\ttfamily` 안에서 곡선 따옴표(“ ” / \enquote)가 `\` 로 깨짐

## 증상

`\ttfamily`(타자기체) 박스 안에서 `\enquote{...}` 또는 직접 입력한 곡선 따옴표 `“ ”`를 쓰면, PDF에서 **여는 따옴표가 `\`(백슬래시)로, 닫는 따옴표가 `"`(직선)로** 렌더링된다.

```
\단계별로 차근차근 생각해줘."
```

(여는 “ 가 `\` 로, 닫는 ” 가 `"` 로 출력됨)

## 원인

기본 폰트 인코딩(OT1)의 타자기체 폰트(cmtt / cm-super sftt)에는 곡선 따옴표 글리프가 제대로 매핑되어 있지 않다. `\enquote`(csquotes)가 만들어내는 `\textquotedblleft`/`\textquotedblright`, 그리고 입력한 유니코드 `“`(U+201C)/`”`(U+201D)가 모두 타자기체 슬롯에서 깨진다. 일반 글꼴(세리프/산세리프)에서는 정상이지만 `\ttfamily` 안에서만 문제가 된다.

## 해결 방법

타자기체(프롬프트 예시) 박스 안에서는 따옴표로 **한글 낫표 `「 」`**(CJK 문장부호)를 쓴다. kotex가 이를 한글 폰트로 라우팅하므로 항상 정상 렌더링된다.

```latex
% 깨짐
\scriptsize \ttfamily \enquote{단계별로 생각해줘.}
\scriptsize \ttfamily “자료에 없음”

% 안전
\scriptsize \ttfamily 「단계별로 생각해줘.」
\scriptsize \ttfamily 「자료에 없음」
```

## 일반 규칙

- `\enquote`/곡선 따옴표 `“ ”`는 **일반 본문 박스에서는 그대로 사용 가능**(정상 렌더링).
- `\ttfamily` 또는 `\texttt{}` 안에서 인용 부호가 필요하면 `「 」`(또는 따옴표 없이 박스 프레임에 맡기기)를 사용한다.
- 직선 ASCII 작은따옴표 `'...'`는 타자기체에서도 무난하게 출력된다.
