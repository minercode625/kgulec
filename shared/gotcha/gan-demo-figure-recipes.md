# 강의용 GAN 데모 그림이 "수렴한 그림"으로 안 나온다

교재용으로 **잘 수렴한 1D GAN** 그림을 만들려는데, 기본 설정으로는 생성 분포가
목표 분포의 **폭을 못 맞추고 바늘처럼 뾰족한 스파이크 두 개**로 주저앉는다.
컴파일·실행 에러는 없고 그림만 설득력이 없다.

**원인** 1차원에서는 $p_{data}$ 와 $p_g$ 의 지지집합이 거의 겹치지 않아
판별자가 즉시 완벽해지고, 생성자는 판별자가 방심한 몇 점에만 질량을 몰아넣는다.

**해결** 세 가지를 함께 쓴다.
- **instance noise**: 판별자에 넣기 전 진짜·가짜 양쪽에 $\sigma$ 를 섞고 학습이 진행되며 0으로 감쇠
- `d_steps = 2`, 학습률 $5\times10^{-4}$, Adam `betas=(0.5, 0.9)`
- 잡음 차원을 1이 아니라 **8~16**으로 (1이면 $G$ 가 단조 사상에 갇힌다)

```python
s = noise0 * max(0.0, 1.0 - t / (0.7 * steps))     # noise0 = 0.35
real, fake = real + s * torch.randn_like(real), fake + s * torch.randn_like(fake)
```

**검산** 생성 샘플의 표준편차를 목표 분포의 이론값과 비교한다(맞으면 폭까지 맞은 것).
스파이크만 남으면 히스토그램 최대 밀도가 이론 최대값의 몇 배로 튄다.

## 모드 붕괴 그림은 반대로 "일부러" 만들어야 한다
생성자를 판별자보다 자주(`g_steps=6`), 큰 학습률(`4e-3`)로 갱신하면
8-가우시안 링에서 재현성 있게 1/8 모드로 붕괴한다.
같은 코드에서 `g_steps=1, d_steps=2, lr=1e-3` 이면 8/8을 덮는다.
**손실 곡선은 두 경우를 구별해 주지 않는다**(붕괴한 쪽이 오히려 이론 균형값
$D: 2\log 2$, $G: \log 2$ 에 더 가깝다) --- 이 사실 자체가 좋은 교육 소재다.
