# 작은 박스에서 분수 분모의 한글이 깨알같이 눌림

**증상** `\scriptsize`/`\footnotesize` tcolorbox 안 인라인 분수의 분모에 한글 단어 → 읽을 수 없이 축소·박스 경계에 붙음. **에러·Overfull 경고 없음** → 시각 검사로만 발견.
**원인** 분자·분모는 scriptstyle(≈70%)로, 중첩 시 또 축소. 본문이 이미 `\scriptsize`면 분모 한글이 본문의 0.5배 이하. 긴 한글이 분모에 들어가면 폭도 넓어져 박스 우측에 닿음.
**해결** 작은 박스에선 한글을 분모로 쓰지 말고 `\div`/괄호로 평평하게: `매출액 $\div\,(1+\text{원가가산이익률})$`. 정렬은 `\phantom{...}`으로 등호 맞춤. 꼭 분수면 `\dfrac`로 크기 유지 후 박스 폭·높이 재확인.
**주의** Overfull 경고를 안 남기므로 **PDF 시각 검사(Agent 위임) 필수**.
