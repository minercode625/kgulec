# `\tfrac`(또는 `\frac`) 분모에 한글 `\text{...}`가 들어가면 작은 박스에서 눌려 깨짐

## 증상

`\scriptsize`/`\footnotesize` tcolorbox 안에서 인라인 분수의 분모에 한글 단어를 넣으면, 분모 텍스트가 **읽을 수 없을 만큼 작게 축소**되고 박스 오른쪽 경계에 붙어 잘린 것처럼 보인다. 컴파일 에러나 Overfull 경고는 **나지 않으므로** LaTeX 로그만으로는 발견되지 않는다 (시각 검사에서만 드러남).

```latex
% 분모 "원가가산이익률"이 깨알같이 작게 눌림
\scriptsize
매출원가 $=$ 매출액 $\times \tfrac{1}{1+\text{원가가산이익률}}$
```

## 원인

분수의 분자·분모는 현재 폰트 크기의 **scriptstyle**(약 70%)로 한 단계, 중첩되면 scriptscriptstyle로 또 줄어든다. 본문이 이미 `\scriptsize`이면 분모의 한글은 본문의 약 0.5배 이하가 되어 가독성이 사라진다. 긴 한글 단어가 분모에 통째로 들어가면 분수 폭도 넓어져 박스 오른쪽에 닿는다.

## 해결 방법

작은 박스 안에서는 **한글이 분모로 들어가는 분수를 쓰지 않는다.** 나눗셈은 `\div` 또는 괄호로 평평하게(inline) 표현한다.

```latex
% 안전: 분수 대신 \div 로 평평하게
매출원가 $=$ 매출액 $\div\, (1 + \text{원가가산이익률})$
```

여러 줄로 정렬할 때는 `\phantom{...}`으로 등호 위치를 맞춘다:

```latex
매출원가 $=$ 매출액 $\times (1 - \text{매출총이익률})$\\
\phantom{매출원가 }$=$ 매출액 $\div\, (1 + \text{원가가산이익률})$
```

## 일반 규칙

- `\scriptsize`/`\footnotesize` 박스 안에서 분수가 필요하면: 분자·분모는 **짧은 기호/숫자만** 두고, 한글 단어는 분수 밖으로 빼거나 `\div`로 표현한다.
- 분수가 꼭 필요하고 분모가 길면 `\dfrac`(displaystyle)로 크기를 유지하되, 박스 폭과 세로 높이를 다시 확인한다.
- 이 문제는 Overfull 경고를 남기지 않으므로 **반드시 PDF 시각 검사(Agent 위임)로 확인**한다.
