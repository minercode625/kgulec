# sectiondividerframe 부제가 길면 좌우 글자 잘림 (에러 없음)

**증상** 섹션 표지 부제(`#2`)가 길면 흰 카드 폭을 넘어 첫/끝 글자가 잘림(예: "하네스…"의 "하"가 소실). 컴파일 에러·Overfull 경고 없이 조용히 잘려 **PDF 시각 검사로만 발견**.
**원인** `\sectiondividerframe`의 부제는 `{\large ...}` 한 줄 중앙 정렬 — 흰 카드(`current page` 기준 좌우 0.85cm 인셋)보다 긴 줄은 카드 밖으로 나가며 배경색에 먹힘.
**해결** 부제는 **한글 기준 약 25자 이내**로 요약(예: "하네스 엔지니어링 실전 --- 효과적인 스킬 설계를 위한 11가지 팁" → "하네스 실전 --- 스킬 설계 11가지 팁"). 섹션 추가·수정 후 표지 전 페이지 렌더 확인 시 부제 폭도 함께 본다.

## frametitle이 수식으로 시작하면 첫 글자가 왼쪽 여백에 잘린다 (에러 없음)

**증상** `\begin{frame}{$\epsilon$을 고르는 방법}` → 렌더된 제목이 "을 고르는 방법"으로 보이고 $\epsilon$이 페이지 왼쪽 경계에서 반쯤 깨져 나온다. Overfull 경고도 에러도 없다.
**원인** frametitle은 왼쪽 여백(`text margin left=0.45cm`)에서 시작하는데, 이탤릭 수학 글리프($\epsilon$ $\ell$ $\gamma$ 등)는 **왼쪽 사이드베어링이 음수**라 그만큼 밖으로 나간다.
**해결** 제목을 수식으로 시작하지 않는다 — 한글·로마자 단어를 앞에 둔다.
```latex
% 위험
\begin{frame}{$\epsilon$을 고르는 방법 --- $k$-거리 그래프}
% 안전
\begin{frame}{$k$-거리 그래프로 $\epsilon$ 고르기}
\begin{frame}{두 파라미터 $\epsilon$과 minPts를 바꿔 보면}
```
**점검** `grep -n '^\\begin{frame}{\$' main.tex` 로 한 번에 찾는다.
