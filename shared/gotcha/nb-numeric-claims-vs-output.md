# 노트북·슬라이드의 수치 주장이 실제 출력과 어긋난다

교재의 서술을 그대로 옮겨 적었는데 **축소한 파라미터에서는 성립하지 않는** 경우다.
컴파일도 실행도 통과하므로 출력을 눈으로 대조해야만 잡힌다.

## `np.argmax(arr < thr)` 는 조건을 만족하는 값이 없어도 0을 돌려준다
**증상** "linear 스케줄에서 abar가 0.05 아래로 내려가는 첫 t = **0**" 처럼
말이 안 되는 값이 인쇄된다. 예외도 경고도 없다.
**원인** `arr < thr`가 전부 False면 `argmax`는 최댓값 위치로 **인덱스 0**을 돌려준다.
**해결** 없을 수 있는 검색은 `np.where`로 명시적으로 처리한다.
```python
def first_below(a, thr):
    idx = np.where(a < thr)[0]
    return int(idx[0]) if len(idx) else None      # 없으면 None
```

## 축소한 하이퍼파라미터에서는 교과서 현상이 재현되지 않는다
**증상** DDPM 데모를 `T=1000` 대신 `T=200`으로 줄였더니 `abar[T-1] = 0.135`가 되어
순방향 끝이 순수 잡음이 아닌데, 역방향은 $N(0,I)$에서 시작한다 --- 앞뒤가 안 맞는다.
슬라이드에는 "확산 끝은 순수 잡음"이라고 써 놓았으니 **자료가 거짓말을 한다.**
**해결** 스텝 수를 줄이면 **강도를 함께 키워** 종점을 맞춘다.
```python
T = 200
beta = np.linspace(1e-4, 0.05, T)        # 1000스텝용 0.02 를 그대로 쓰면 안 된다
abar = np.cumprod(1 - beta)
print(abar[-1])                          # 0에 가까운지 반드시 인쇄해 확인
```
**일반 규칙** 슬라이드에 쓴 정성적 주장마다 노트북에서 **그 값을 인쇄**하게 만들고,
검증 실행의 stdout을 실제로 읽는다. `PASS/FAIL`만 보면 이 부류는 전부 통과한다.

## 데모가 원리상 성립할 수 없어 아무것도 증명하지 못한다
**증상** 셀프 어텐션에게 "바로 앞 토큰을 보라"를 학습시키는 데모에서 손실이
`0.94 -> 0.73`에서 멈추고 어텐션 지도에 아무 구조도 안 생긴다. 에러·경고 없음.
**원인** 입력이 무작위 벡터뿐이면 점수 $q_t^\top k_s$가 **내용**에만 의존한다.
셀프 어텐션은 순열 등변이므로 **위치 기반 패턴은 학습 자체가 불가능**하다.
**해결** Q·K 입력에 위치 인코딩을 더한다. 장난감 규모($d\approx16$)에서는
PE를 내용보다 크게(×3) 주고 `base`도 작게(100) 잡아야 수렴이 눈에 보인다.
학습 후 **부대각선 평균 가중치를 인쇄**해 0.8 이상인지 확인한다.

## 버그 재현 데모가 정상 동작과 구별되지 않는다
**증상** 인과 마스크를 빼면 "손실은 0으로 가는데 생성이 무너진다"를 보이려 했는데
마스크 유무 양쪽이 **똑같이 올바른** 수열을 생성한다. 탐침(미래 토큰 교란)도 차이가 없다.
**원인** 데이터가 왼쪽 문맥만으로 완전히 예측 가능하면 모델이 미래를 볼 이유가 없다.
게다가 생성은 **마지막 위치만** 쓰는데 그 위치는 마스크가 없어도 볼 미래가 없다.
**해결** **무작위 토큰**을 쓴다. 정직한 모델의 손실 하한이 $\ln(V-1)$로 고정되므로
그 아래로 내려가는 것 자체가 누수의 증거다. 여기에 "$x_{t+1}$만 바꿔 보고
위치 $t$의 예측이 따라가는가" 탐침을 더하면 결정적이다.
```python
floor = math.log(V - 1)        # 무작위 데이터의 정보이론적 하한
# mask ON  -> 2.4049 (하한에 붙음)   mask OFF -> 0.2415 (하한 아래 = 버그)
```
**일반 규칙** 데모를 만들 때 **정직한 모델의 이론적 하한(또는 무작위 추측 정확도)을
먼저 계산해 함께 인쇄**한다. 그 기준선이 없으면 "학습이 됐다/안 됐다"를 판정할 수 없다.
