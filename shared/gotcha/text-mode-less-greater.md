# 텍스트 모드의 < 와 > 가 ¡ ¿ 로 출력됨

## 증상

본문/박스/TikZ 노드 안에서 `<` 와 `>` 를 그대로 쓰면 PDF에서 **¡** 와 **¿** (스페인어 거꾸로 느낌표/물음표) 또는 부등호와 다른 글리프로 출력된다.

```latex
% 깨짐 — < 가 ¡ 로, > 가 ¿ 로 표시됨
\node {중간값 5 < 7};
\node {12 > 7};
교수 100명의 추천 > 친구 100명의 추천.
```

## 원인

표준 LaTeX 텍스트 폰트(특히 Computer Modern, Latin Modern 계열)는 `<`/`>` 글리프를 **부등호가 아니라 다른 기호**로 매핑한다. 이는 LaTeX의 고전적 함정으로, T1 인코딩이 아닌 OT1 인코딩이 활성일 때 더 두드러진다.

TikZ 노드의 텍스트도 동일하게 텍스트 모드로 처리되므로 같은 문제가 발생한다.

## 해결 방법

**부등호는 항상 수식 모드에서 사용한다.**

```latex
% 수정 1: $...$ 로 감싸기
\node {중간값 $5<7$};
\node {$12>7$};
교수 100명의 추천 $>$ 친구 100명의 추천.

% 수정 2 (대안): \textless / \textgreater 매크로
교수 100명의 추천 \textgreater{} 친구 100명의 추천.
```

## 일반 규칙

본문/tcolorbox/TikZ 노드 어디서든 부등호가 필요하면 `$<$`, `$>$`, `$\leq$`, `$\geq$` 처럼 항상 수식 모드. 단순 ASCII `<`/`>`를 텍스트로 두지 말 것.

`->` 같은 화살표 표기도 텍스트 모드에서는 깨질 수 있어 보통 `$\to$` 또는 TikZ `[->]` 옵션으로 처리한다 (TikZ의 `\draw[->,...]` 옵션과 `>=Stealth` 옵션 안의 `>`는 키 파서가 처리하므로 안전).
