# 모드 B: 강의자료 수정 및 보완 (`/kgulec:edit`)

공유 자료 위치: **`${CLAUDE_PLUGIN_ROOT}/shared/`** (이 스킬 기준 `../../shared/`). 아래에서 `shared/`로 표기.
.tex 수정 규칙은 **`shared/slide-authoring-rules.md`**(디자인·분량·오버플로우·주의)를 반드시 함께 읽는다.

## 0단계: 설정 로드 + 마이그레이션

수정이 타이틀(교수명·소속·테마색)에 영향을 주거나 새로 생성할 가능성이 있으면, 모드 A(`/kgulec:new`)의 **0단계와 동일하게** `shared/config-schema.md` + `~/.claude/kgulec/config.md`를 읽고 탑업 마이그레이션한다.

## 수정 대상

사용자 입력대로 기존 `main.tex`를 수정한다(파일 위치는 사용자의 폴더 구조에 따른다 — `weekN/` 강제 없음).

| 작업 유형 | 예시 |
|-----------|------|
| **내용 수정** | 오류 정정, 설명 개선, 수식·코드 수정 |
| **슬라이드 삭제** | 불필요한 슬라이드 제거 |
| **순서 변경** | 슬라이드·섹션 재배치 |
| **슬라이드 교체** | 기존 슬라이드를 새 내용으로 대체 |
| **내용 보완** | 새 슬라이드 추가, 기존 슬라이드 보강 |

## 규칙

- 수정 전 **번들 `shared/gotcha/` + 사용자 `~/.claude/kgulec/gotcha/`(있으면)의 .md를 모두 읽고** 동일 실수를 반복하지 않는다.
- 추가·보완에 자료가 필요하면 **모드 A 2단계의 "`./ref` 우선 활용"** 규칙을 동일 적용. `./figs`·`./ref`가 필요한데 없으면 모드 A처럼 자동 생성하고 넣을 그림·참고자료가 있는지 먼저 물어본다.
- 새 이미지가 필요하면 **모드 A 6단계의 "`./figs/` 우선"** 규칙을 동일 적용(관련 이미지만 삽입, 없으면 TODO 주석).
- 타이틀/테마를 새로 반영해야 하면 config의 `professor`/`department`/`theme_colors`를 모드 A 6단계 오버레이대로 적용한다.
- 수정·보완된 슬라이드에 **모드 A 7단계(품질 검사, 오버플로는 Agent 위임)** 를 동일 수행하고 문제 시 자동 수정.
- **섹션 표지(divider) 재확인**: 모드 A 7단계의 「섹션 표지 재확인」을 동일 수행한다. `\sectiondividerframe` 배경 overlay는 페이지 위치에 의존하므로 **섹션 추가·삭제·순서 변경이 있었으면 바뀐 표지만이 아니라 모든 섹션 첫 표지**를 다시 렌더 확인하고 2~3회 재컴파일한다(뒤쪽 표지가 따라 어긋날 수 있음).
- 발견·해결한 새 에러는 **모드 A 8단계(Gotcha 기록)** 를 동일 수행 — **사용자 폴더 `~/.claude/kgulec/gotcha/`에 기록**(없으면 생성), 번들 `shared/gotcha/`엔 쓰지 않는다.
