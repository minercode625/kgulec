# 모드 C: 실습코드 만들기 (`/kgulec:code`)

사용자가 실습코드를 요청하면:

1. 먼저 대상 강의자료의 `main.pdf`를 읽어 강의 내용을 파악한다.
2. 수업시간에 보여줄 수 있는 실습 내용을 **3가지 이상 추천**한다.
3. 사용자가 선택하면 강의자료(`main.tex`/`main.pdf`)와 같은 폴더의 `code/` 하위 디렉토리에 실습 프로그램을 작성한다(`weekN/` 구조를 강제하지 않는다).

## 실습 코드 규칙

- Python 또는 HTML/CSS/JS로 작성(주제에 따라 유연하게 선택).
- Python 실습: 개별 `.py` 또는 Jupyter notebook(`.ipynb`).
- HTML 실습: `file://`로 직접 실행 가능(순수 HTML/CSS/JS, 프레임워크/CDN 금지).
- 교실 프로젝터(1920x1080) 최적화 우선.
- 교육 목적: 알고리즘 단계별 시각화, 인터랙티브 데모.
